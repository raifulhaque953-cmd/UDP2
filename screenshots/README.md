# Screenshots

This directory is designated for application screenshots captured directly from an Android device or emulator running PocketShark.

### Recommended Screen Captures:

| Filename | Screen / View | Description |
| :--- | :--- | :--- |
| `01_capture_dashboard.png` | **Capture Screen** | Live traffic waveform graph, shark fin capture button, and 3×2 stat cards with sparklines. |
| `02_protocol_distribution.png` | **Protocol Distribution** | Interactive donut chart and detailed protocol breakdown. |
| `03_packet_list.png` | **Packets Screen** | Virtualized packet list with protocol badges and search/filter chips. |
| `04_packet_detail_hex.png` | **Packet Detail Screen** | Collapsible header sections (IPv4, TCP/UDP/ICMP, DNS) and formatted Hex + ASCII dump. |
| `05_analytics_traffic.png` | **Analytics Screen** | Historical throughput graph, top conversations, top IPs, and DNS query rankings. |
| `06_connections_tracker.png` | **Connections Screen** | Active endpoint tracking with connection states and byte counters. |
| `07_security_alerts.png` | **Security Screen** | Risk overview card, threat categories, and detected alert feed. |
| `08_settings_configuration.png` | **Settings Screen** | Glassmorphic configuration controls (MTU, DNS, Subnet, UI preferences). |

> **Note:** Screenshots should be captured at device native resolution (e.g., 1080×2400) in dark theme.
